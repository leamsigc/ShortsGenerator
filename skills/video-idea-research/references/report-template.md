# Report Template — Video Idea Research

The final deliverable has exactly two sections: **the top 10 videos the
research found** and **the 5 video ideas** (titles + 3 scripts each + YouTube
metadata). Generated by
`node "$CLAUDE_SKILL_ROOT/scripts/build-ideas-report.js" <video-ideas.json>`
which writes `ideas-report.md` + `REPORT.html` next to the input file.

## REPORT.html requirements

Self-contained (no network), dark theme, printable:
- Header: topic, platform, window, date, audience, generated-by note.
- Section 1: sortable-looking table of the top 10 videos (title links to the
  URL), views, window, velocity, hook type; expandable outline per video
  (`<details>` element) so the skeletons that fed the ideas are auditable.
- Section 2: one card per idea with hotness badge, view-estimate range,
  audiences with score chips, the 3 scripts side-by-side or tabbed, and the
  YouTube metadata block in a copy-friendly `<pre>`.
- Footer: methodology note (ranking metric, window, template sources).

## Quality bar (the end goal: views that keep accruing)

- Every idea cites ≥2 real top videos with real view counts.
- Every script is paste-ready for TTS/short-generator — pure spoken text.
- Every title scores against the youtube-title rubric (SEO / power /
  specificity / stake / format) — honest clickability, no bait-and-switch.
- Tags/keywords cover Spanish + English search phrasings of the entities.
- Missing data (views: null) is shown as "—", never fabricated.
